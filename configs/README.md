# 模型配置字段说明

`openbmi.json` 和 `hgd.json` 使用标准 JSON 格式。JSON 不支持注释，因此字段解释集中写在这里，配置文件本身仍可直接读取。

| 字段 | 含义 | OpenBMI | HGD |
|---|---|---:|---:|
| `num_channels` | 每条 EEG 试次包含的电极通道数；用于空间卷积和输入形状检查。 | 20 | 44 |
| `classes` | 输出的分类类别数；模型为每个类别产生一个得分。 | 2 | 4 |
| `n_times` | 每条试次沿时间维的采样点数；决定原始分支展平后的特征长度。 | 1000 | 1000 |
| `sampling_rate` | 采样率，单位 Hz；用于计算 FFT 频率轴和滤波器响应。 | 250.0 | 250.0 |

在默认配置下，1000 个时间点除以 250 Hz 对应 4 秒。数据加载后，模型输入形状为 `[试次数, 1, 电极通道数, 时间点数]`，输出形状为 `[试次数, 类别数]`。

这些字段描述数据尺寸和采样设置。固定的五频带、共享频带编码器、等权聚合、原始分支去时间均值以及残差融合系数的定义见 `model/npf_eegnet_rd.py` 的逐行中文注释；训练参数的解释见 `train.py` 和 `training/engine.py`。
